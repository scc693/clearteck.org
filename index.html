Import format & privacy

Accepts Health workout JSON containing a workout array, or a JSON array of {date, activity: "cycling", miles, minutes, mode: "assisted" or "unpowered"}. Elapsed start-to-end time is used when available. Import does not connect directly to Apple Health. No workout records are sent to mapping services or saved in GitHub. Untagged rides must be assigned a mode before calibration.

MAKE IT YOURS

Map services

Defaults use public community services. Requests may be throttled or unavailable. Replace with compatible hosted services as usage grows.

Use HTTPS services with browser CORS access. The default is OpenFreeMap’s OSM vector map. Replacements must retain appropriate attribution. Locations are sent to the chosen routing/search provider; map providers receive tile requests. Saved routes and history remain on your device.

Honest estimates.

Cycleway uses OpenStreetMap data and BRouter’s bicycle routing profiles. You can change the preference, request an alternative, or add via points to follow your preferred roads.

Trip time = distance ÷ riding speed + expected stops + other delay. Expected stops = mapped signal clusters × chance of stopping × wait when stopped. Nearby signal tags within 45 metres are grouped; this is an approximate intersection count.

There is no live traffic feed or signal phase timing. Elevation is returned by the router; the speed you choose should already reflect the hills. Historical pace includes stops, so no extra delays are added in that mode.

Imported GPX tracks retain their exact geometry. Their signals and turn instructions are unknown until you rebuild a route from points. This is a planning tool, not live turn-by-turn navigation.

Data: OpenStreetMap contributors · ODbL. Routing: BRouter. Search: Photon. Basemap: OpenFreeMap / OpenMapTiles. Mapping: OpenLayers (Canvas).
